# Pingjie Wang's Homepage

Personal academic homepage for <https://applewpj.github.io/>, built with the [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) Jekyll template.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://127.0.0.1:4000/>.

## Main content

- Profile and social links: `_config.yml`
- Introduction: `_pages/includes/intro.md`
- News: `_pages/includes/news.md`
- Publications: `_pages/includes/pub.md`
- Experience and education: `_pages/includes/honers.md`
- Open source, academic service, and skills: `_pages/includes/others.md`
