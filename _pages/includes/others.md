# 💻 Open Source

- [**Token Learning Spectrum**](https://github.com/applewpj/token-learning-spectrum): code and public loss matrices for decomposing smooth scaling laws into token-level learning events.
- [**NTK-Selector**](https://github.com/applewpj/NTK-Selector): transferable auxiliary-data selection for low-resource domains using a practical NTK approximation.
- [**LIAR**](https://github.com/applewpj/LIAR): retraining-free reconstruction for pruned language models.
- [**P-pruning**](https://github.com/applewpj/P-pruning): task-aware pruning before fine-tuning.
- [**AuscultaBase**](https://github.com/applewpj/AuscultaBase): a generalist audio foundation model and benchmark for body-sound auscultation.
